# 🌐 Full-Stack Developer Portfolio — Aziz Achour

An interactive, responsive, and modern Full-Stack Developer portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

🔗 **Live Demo:** [https://portfolio-aziz-achour.vercel.app/](https://portfolio-aziz-achour.vercel.app/)

---

## ✨ Features

- ⚡ **High Performance & Responsive:** Mobile-first architecture powered by Vite and Tailwind CSS.
- 🎨 **Modern Neon UI:** Custom tech-focused dark theme with interactive filtering for skills and projects.
- 💼 **Architecture Case Studies:** Detailed modals explaining system architecture, databases, and code logic for key projects (*Talantys*, *Electrical Invoicing SaaS*, *Univibes*).
- 💻 **Interactive Terminal:** Live terminal component showcasing software development methodology and clean code principles.
- 📄 **CV Preview & Contact:** Built-in resume viewer and contact form with instant email copying.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Deployment:** Vercel
