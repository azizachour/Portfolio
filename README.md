# Portfolio — Aziz.dev

Portfolio développeur Full-Stack Web & Mobile moderne conçu avec **React**, **TypeScript**, **Tailwind CSS** et **Vite**.

## 🚀 Démarrage rapide

### Installation des dépendances
```bash
npm install
```

### Lancer en développement
```bash
npm run dev
```

### Compiler pour la production
```bash
npm run build
```

### Prévisualiser le build de production
```bash
npm run preview
```
